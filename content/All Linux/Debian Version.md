

> Note : Debian ada banyak version ikut 'stability'.

1. Trixie (Stable)
    - Official version yang dah stabil, full run test and recommended for usage (workstation/server)  dan jarang ada bug.
2. Forky (Testing)
	- Testing version sebelum stable version.
    - Ada software yang baru tapi masih dalam testing period untuk cari bugs sebelum jadi stabil. 
3. Sid (Unstable)
	- Development version yang selalu akan diupdate every day dengan software paling baru yang menjadikan dia kurang stabil.
