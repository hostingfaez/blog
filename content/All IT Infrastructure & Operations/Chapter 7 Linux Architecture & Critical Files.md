### Critical Files (Debian)

1. Authentication & user activity

```bash
/var/log/auth.log
```

2. User account info

```
/etc/passwd
```

3. Hashed passwords

```
/etc/shadow
```

4. Network and firewall configs

```
/etc/hosts
```

5. SSH server configuration

```
/etc/sshd/sshd_config
```

6. DNS resolve config

```
/etc/resolve.conf
```
