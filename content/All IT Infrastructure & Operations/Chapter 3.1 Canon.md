Boleh pergi dekat Canon Malaysia website or in this link : https://my.canon/en/support 

Search your model name printer. Pastikan amik yang **FOR LINUX**.

![[Pasted image 20260719224445.png]]

Extract file and then masuk dalam folder sampai nampak ada file nama `install.sh`. Masuk dalam terminal and pastikan dalam folder yang ada install.sh tu.

```bash
chmod +x install.sh
sudo ./install.sh 
```

Then pilih korang punya printer.
![[Pasted image 20260719224744.png]]
Tekan add. Boleh close setup and dia akan auto tunjuk dekat settings kita dekat bahagian printer.
