For example ip address and subnet server:

```
192.168.0.100 255.255.255.0
```

> Tips: Kalau nak better security pastikan server dalam subnet yang lain tak sama dengan peripherals yang lain.

Korang kena access router via web browser (firefox,chrome) dekat mana mana computer dengan syarat korang connect dalam network yang sama. By default ip router adalah sama (may differ).

```
http://192.168.1.1
```

Bila dah masuk pastikan korang exclude ip address server. Kenapa kena exclude? 

So router ni tugas dia adalah bagi ip address kepada device yang connect dalam network. Contoh phone,computer,printer etc and semua tu ada ip address untuk communicate. Kita exclude sebab kita nak **make sure** server je yang dapat ip address and bukan device yang lain and pastikan router tak bagi ip address server dekat device lain.
