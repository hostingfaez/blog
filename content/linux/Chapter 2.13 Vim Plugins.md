Vim Plug : Plugin Manager untuk vim 

Install Vim Plug

```
curl -fLo ~/.vim/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

My Vim Config : https://github.com/FaezBun/mydotfiles/blob/main/vim.conf 

Nak install plug

```
:PlugInstall
```
