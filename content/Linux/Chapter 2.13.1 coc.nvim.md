Install (tekan : )

- **Python:** `:CocInstall coc-pyright`
- **C / C++:** `:CocInstall coc-clangd` & `sudo apt install clangd -y`
- **HTML / CSS / JavaScript:** `:CocInstall coc-tsserver coc-html coc-css`
- Markdown : `:CocInstall coc-markdownlint`
